# X (Twitter) Content Skill — Abvorn

## Platform Rules
- **Tone:** Sharp, opinionated, conversational
- **Max Hashtags:** 3
- **Caption Length:** 100–150 chars
- **Hook Style:** Hot take, bold statement, insight
- **Visual Style:** Bold text, high contrast, single image

## Viral Hook Templates
- "I test {product} for a living. Here's the hot take:"
- "Everyone is wrong about {product}."
- "The {product} market is broken. Here's what wins:"
- "I analyzed 1,000 reviews of {product}. Surprising."

## Anti-Patterns
- × No long threads for a single verdict
- × No generic takes
- × No more than 3 hashtags
- × No low-contrast images

## Winning Format
- Punchy one-line verdict
- Score card visual
- Link in bio / first comment
